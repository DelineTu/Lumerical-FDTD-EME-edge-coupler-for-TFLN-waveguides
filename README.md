# Lumerical_FDTD-EME_inverse_taper-edge_coupler_on_TFLN_waveguides\

This repository contains the design and simulation results of inverse tapers and edge couplers implemented on both thin-film lithium niobate (TFLN) and silicon nitride (SiN) platforms, using Ansys Lumerical FDTD and EME.

The objective is to enable efficient coupling for balanced homodyne detection of squeezing generated by an **on-chip OPO on 300-nm TFLN film**.
Different output modal profiles are designed for* free-space detection* and *fiber-based detection*, optimized for **transmission efficiency** and **mode overlap with target Gaussian profiles**.

# Elliptical Design

For circular output beams on thin-film platforms, **aspheric lens geometries** are explored for collimation.
Elliptical collimation lenses are also designed to reshape the highly anisotropic TFLN waveguide modes.
